# Chatbot JAIS

A chatbot project developed during my internship at Selangor Human Resource Development Centre (SHRDC), focusing on Generative AI, Retrieval-Augmented Generation (RAG), and workflow automation.

## Project Overview

This project explores the development of a chatbot workflow using Langflow and n8n. The Langflow workflow uses a RAG approach to retrieve relevant information from a knowledge source, while n8n supports workflow automation and integration.

## Technologies Used

- **Langflow** — AI workflow development and RAG implementation
- **n8n** — Workflow automation and integrations
- **Retrieval-Augmented Generation (RAG)** — Retrieving relevant context to support chatbot responses

## Project Files

- `Chatbot JAIS (Langflow).json` — Exported Langflow workflow
- `Chatbot JAIS (n8n).json` — Exported n8n workflow

## Purpose

This project provided hands-on experience in building AI chatbot workflows, connecting components, and exploring automation for practical use cases.

## Notes

These files contain exported workflow configurations. Additional setup, dependencies, credentials, and access to the relevant knowledge source may be required to run the workflows.

*This repository is intended for portfolio and learning purposes.*
